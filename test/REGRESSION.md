# 固定回归场景

- 普通题目：日文原位替换、纯英文不变、保留英文内部换行及 Unicode 空白、模型破坏英语时回退。
- 内嵌教材：来源校验、日文翻译、查词上下文、共享缓存、暂停与取消；请求失败在主面板显示显式重试，状态轮询中断后可恢复。
- 学习记录：选中标签、原生下拉选项及其值保持不变。
- 查词：连字符、单词划选、多义词上下文、词性分行。
- 划选：嵌套文本、自动翻译、窗口边缘与狭小视口定位。
- 切题与结果页：已完成/缓存弹窗关闭，未完成请求取消。
- 网络与恢复：交互优先、排队取消、局部失败隔离和显式重试。
- 设置与升级：首次配置、开关、缓存策略版本、固定提交安装链接；持久化保留 LRU 顺序，多标签页清除后不恢复旧缓存或待写入结果。

`npm run check` 运行自动测试、构建及语法检查。`npm run demo` 提供无真实 API 调用的交互验证页。
